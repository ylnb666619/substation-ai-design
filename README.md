# 预制舱变电站一体化设计与结构优化

基于 BIMBase 平台的预制舱式变电站参数化建模与构件级力学验算一体化方案，包含**参数化构件库**、**自然语言驱动的自动建模 Agent** 和 **AI 辅助的力学验算平台**三部分。

---

## 项目简介

预制舱式变电站在工厂内完成舱体与设备的预制装配，再整体运输至现场吊装。传统工作流里，建模、算量、结构验算分散在不同工具中，模型一改，荷载和验算结果就得全链路重做。

本项目把这条链路收进同一个 BIMBase 环境：

- **参数化构件库** —— 覆盖配电设备、舱体结构、围护、配套设施、基础底座五大族的 Python 构件插件，拖放即用，改参数秒级重建，任意参数组合不产生废模。
- **自动建模 Agent** —— 用自然语言描述舱型与设备配置，Agent 完成需求解析、生成前约束校核，直接装配真实构件并输出可复现的方案包。
- **力学验算平台** —— 读取模型语义与荷载，按 GB 50017 做构件级验算并生成计算书，支持大模型辅助分析与知识库检索。

三者的公共约定是：**每根构件都自带几何与力学信息**。算量、验算、报告的数据都从模型本体读取，不靠人工二次录入。

## 技术架构

### 一、参数化构件库

基于 **BIMBase PyP3d** 二次开发接口构建，每个构件是一个独立的 Python 脚本插件，即插即用。全部构件统一采用 `Component + Attr` 参数面板，并以 `@export` 装饰器标注 `replace()` 方法——拖动参数即触发重建，参数变更秒级响应。

构件族划分：

| 族 | 代表构件 |
|---|---|
| 配电设备族 | 干式变压器、中置柜（KYN28-12）、环网柜（HXGN）、GGD 低压柜、GCS 低压柜、壁挂配电箱 |
| 预制舱结构 | 空心方矩管立柱、屋面龙骨（三角桁架）、山墙挡墙 |
| 预制舱围护 | 三层复合墙、屋面面层（分层构造版 / 简单版）、绝缘内壁面层 |
| 配套设施 | 双层对开门、逃生门、玻璃窗、轴流风机通风口、灭火器、舱内吊顶系统 |
| 基础底座 | 标准三段底座、左右分区底座、四区密格底座、错缝拼接底座 |

几项贯穿全库的做法：

- **参数驱动布局**：GGD 的"回路数"、GCS 的"抽屉数"、玻璃窗的"分格模式"、屋面龙骨的动态分档——改一个参数，柜内回路或屋面杆件布局自动重排。
- **同名参数拼接契约**：屋面龙骨、屋面面层、山墙挡墙共用"整体宽度 / 起坡高度"，同源同名同默认值，设为相同数值后坡角、脊线、接缝自动共面。
- **零布尔优先建模**：大量几何用实体拼装而非布尔运算，仅在低风险场景使用布尔求差 / 求并，其余合并一律用几何合成。
- **数据随模型输出**：槽钢底座逐杆输出编号、长度、截面面积、理论重量、容许弯矩、承重量与起止坐标，写入构件属性并汇总 JSON；三层复合墙输出三层各自的体积与重量。
- **力学信息随模输出**：构件带只读的"力学信息"参数组，由几何尺寸与材料密度自动计算并回写，可直接供恒载统计与 GB 50017 验算取数。

### 二、自动建模 Agent

运行环境：BIMBase 2025 / Pro / V1.6，Python 插件 SDK 1.6.2。

主链七步：需求解析 → 尺寸模式判定 → 平面模组库匹配 → 底座梁格方案 → 真实构件装配与放置 → 生成前约束校核 → 方案包输出。

关键设计：

- **与构件库的双插件协同** —— Agent 通过 `component_ref` 调用链使用构件库中的真实构件，而不是生成抽象几何。产物在 BIMBase 里可直接继续编辑。
- **失败保护** —— 每次生成都落一份方案包，成功与失败都留档；约束不满足时给出建议卡而不是产出废模。
- **路径自适应** —— 一体化安装包可移植，换机器不改配置。

### 三、AI 力学验算平台

| 层 | 技术栈 | 职责 |
|---|---|---|
| 前端 | Vue 3 + Three.js | 登录、项目切换、三维模型、构件详情、荷载、验算、报告、知识库 |
| 后端 | Python 3 + FastAPI | 身份认证、项目文件管理、模型适配、验算接口、Agent 调用、报告生成 |
| 计算 | 本地力学模块 | 构件级验算，数值结果本地计算 |

系统以 FBX 展示原始几何，以 `scene.json` 提供构件语义与验算参数；数值结果由本地力学模块计算，大模型（DeepSeek）用于辅助验算与报告撰写。

主要功能：模型与构件查看、荷载与边界条件维护、按模型重算自重、构件验算、规范管理、计算书生成与下载、力学验算 Agent、知识库检索。

## 快速开始

1. 解压 `5. AI 搭建平台安装包.zip`，按 `6、AI搭建平台说明文档.zip` 中的安装说明部署自动建模 Agent。
2. 解压 `8. AI力学验算平台安装包.7z`，参照 `9. AI力学验算平台使用说明.docx` 配置环境变量与模型服务。
3. 用 `2、预制电力舱场景模型.p3d` 在 BIMBase 中打开场景模型，或在 Agent 中用自然语言描述舱型重新生成。
4. 在验算平台中导入模型，维护荷载与边界条件后执行构件验算并导出计算书。

构件库的逐构件参数、默认值、分组与取值范围，见 `3、场景构件及参数说明.docx`。

## 说明

- 构件库与场景模型为**参数化几何示意模型**，用于方案阶段的布局规划、算量与荷载统计，不替代产品设计、型式试验或施工图。
- 配电设备族为几何示意，不具备实际电气运行功能；避雷器、接地装置等成套配套件未建模。
- Agent 内置的尺寸、净距与顺序假设需工程师复核后用于工程实践。
- 本仓库未声明开源许可，仅供学习交流与工程参考。
